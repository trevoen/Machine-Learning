\section{Definição do Problema e Coleta de Dados}

\subsection{Descrição do Problema}

Este trabalho tem como objetivo desenvolver modelos preditivos baseados em Aprendizado de Máquina para classificar compostos químicos quanto à sua mutagenicidade segundo o teste de Ames. O teste de Ames é amplamente utilizado para avaliar o potencial mutagênico e cancerígeno de substâncias químicas, sendo fundamental para a área de toxicologia e desenvolvimento de novos fármacos.

\textbf{Tarefa:} Classificação binária (mutagênico vs. não-mutagênico)

\subsection{Dataset Utilizado}

Foi utilizado o \textit{Ames Mutagenicity Dataset}, disponível publicamente em:

\url{https://data.mendeley.com/datasets/ktc6gbfsbh/2}

\textbf{Referência:} Martínez, M.J., Sabando, M.V., Soto, A.J., Roca, C., Requena-Triguero, C., Campillo, N.E., Páez, J.A., \& Ponzoni, I. (2022). \textit{Multi-Task Deep Neural Networks for Ames Mutagenicity Prediction}. ChemRxiv. DOI: 10.26434/chemrxiv-2022-852tf

\subsection{Caracterização dos Dados}

O dataset contém informações sobre \textbf{5,536 compostos químicos} avaliados pelo teste de Ames, com as seguintes características:

\begin{itemize}
    \item \textbf{Número de instâncias:} 5,536 compostos
    \item \textbf{Número de features:} 1,371 descritores moleculares (calculados com Mordred)
    \item \textbf{Variável alvo:} Coluna \texttt{Overall} - label de consenso para mutagenicidade Ames
    \item \textbf{Features adicionais:} TA98, TA100, TA102, TA1535, TA1537 (labels específicas por cepa bacteriana)
    \item \textbf{Partições originais:} Train, Internal, External (conforme artigo original)
\end{itemize}

\subsection{Distribuição das Classes}

A análise exploratória revelou a seguinte distribuição da variável alvo:

\begin{itemize}
    \item \textbf{Classe 1 (mutagênico):} 3,103 amostras (56.05\%)
    \item \textbf{Classe -1 (não-mutagênico):} 2,202 amostras (39.78\%)
    \item \textbf{Classe 0 (indefinido):} 231 amostras (4.17\%)
\end{itemize}

Observa-se um \textbf{desbalanceamento moderado} entre as classes, com predominância de compostos mutagênicos (56\% do dataset). Este desbalanceamento deverá ser considerado na etapa de pré-processamento e na escolha das métricas de avaliação.

\subsection{Estratégia de Pré-processamento}

Com base na análise exploratória, foi definida a seguinte estratégia de pré-processamento:

\subsubsection{Remoção de Colunas Não-Informativas}

\begin{itemize}
    \item Remoção de colunas de metadados: \texttt{Id}, \texttt{Name}, \texttt{CAS}, \texttt{SMILES RDKit}
    \item Remoção de colunas de partição original: \texttt{Partition}
    \item Remoção de labels auxiliares de cepas: \texttt{TA98}, \texttt{TA100}, \texttt{TA102}, \texttt{TA1535}, \texttt{TA1537}
\end{itemize}

\subsubsection{Tratamento da Classe Indefinida}

Devido à pequena quantidade de amostras com classe indefinida (4.17\%), optou-se por \textbf{remover} essas 231 instâncias, resultando em um problema de classificação binária puro com 5,305 amostras.

\subsubsection{Normalização das Features}

Foi aplicada normalização por \texttt{StandardScaler} (z-score) em todas as features numéricas para:

\begin{itemize}
    \item Garantir mesma escala para todos os descritores moleculares
    \item Melhorar convergência de algoritmos baseados em gradiente
    \item Evitar dominância de features com maior magnitude
\end{itemize}

\subsubsection{Divisão dos Dados}

Os dados foram divididos utilizando \texttt{train\_test\_split} com estratificação:

\begin{itemize}
    \item \textbf{Conjunto de treino:} 70\% (3,713 amostras)
    \item \textbf{Conjunto de teste:} 30\% (1,592 amostras)
    \item \textbf{Estratificação:} Mantém proporção das classes em ambos conjuntos
    \item \textbf{Random state:} 42 (reprodutibilidade)
\end{itemize}

\section{Abordagem, Algoritmos e Estratégia de Avaliação}

\subsection{Abordagem do Problema}

O problema foi abordado como uma tarefa de \textbf{classificação binária supervisionada}, onde o objetivo é prever se um composto químico é mutagênico (classe 1) ou não-mutagênico (classe -1) com base em seus descritores moleculares.

\subsection{Algoritmos Selecionados}

Para o spot-checking, foram selecionados \textbf{8 algoritmos} de diferentes famílias de aprendizado de máquina, garantindo diversidade nas abordagens:

\subsubsection{Modelos Lineares}

\begin{itemize}
    \item \textbf{Logistic Regression:} Modelo linear clássico para classificação binária, eficiente e interpretável.
    \item \textbf{SVM Linear:} Support Vector Machine com kernel linear, busca hiperplano de margem máxima.
\end{itemize}

\subsubsection{Modelos Baseados em Árvores}

\begin{itemize}
    \item \textbf{Decision Tree:} Modelo não-linear baseado em particionamento recursivo, altamente interpretável.
    \item \textbf{Random Forest:} Ensemble de árvores de decisão, robusto a overfitting e eficiente em dados de alta dimensionalidade.
\end{itemize}

\subsubsection{Modelos de Boosting}

\begin{itemize}
    \item \textbf{Gradient Boosting:} Ensemble sequencial que constrói modelos corrigindo erros dos anteriores, geralmente apresenta alta performance.
\end{itemize}

\subsubsection{Modelos Baseados em Instâncias}

\begin{itemize}
    \item \textbf{K-Nearest Neighbors (KNN):} Classificação baseada em similaridade local, não-paramétrico e simples.
\end{itemize}

\subsubsection{Modelos Probabilísticos}

\begin{itemize}
    \item \textbf{Naive Bayes:} Modelo probabilístico baseado em independência condicional, rápido e eficiente.
\end{itemize}

\subsubsection{Redes Neurais}

\begin{itemize}
    \item \textbf{MLP Neural Network:} Rede neural artificial multi-camadas, capaz de aprender relações não-lineares complexas.
\end{itemize}

\subsection{Justificativa da Diversidade}

A seleção de algoritmos de diferentes famílias permite:

\begin{itemize}
    \item Explorar diferentes hipóteses sobre a estrutura dos dados
    \item Identificar se o problema favorece modelos lineares ou não-lineares
    \item Avaliar trade-offs entre interpretabilidade e performance
    \item Comparar eficiência computacional entre diferentes abordagens
\end{itemize}

\subsection{Métricas de Avaliação}

Devido ao desbalanceamento moderado das classes (56\% vs 40\%), foram utilizadas as seguintes métricas:

\begin{itemize}
    \item \textbf{Accuracy:} Proporção de predições corretas (métrica geral)
    \item \textbf{Precision:} Proporção de positivos preditos que são verdadeiros positivos
    \item \textbf{Recall:} Proporção de positivos reais que foram identificados
    \item \textbf{F1-Score:} Média harmônica entre Precision e Recall (métrica balanceada)
    \item \textbf{ROC-AUC:} Área sob a curva ROC, mede capacidade discriminativa do modelo
\end{itemize}

A \textbf{Accuracy} foi priorizada como métrica principal para o ranking dos modelos, complementada pela análise das demais métricas.

\subsection{Estratégia de Validação}

Foi utilizada \textbf{validação cruzada estratificada} (\textit{Stratified K-Fold Cross-Validation}) com \textbf{5 folds}:

\begin{itemize}
    \item Garante que cada fold mantenha a proporção das classes
    \item Fornece estimativa mais robusta da performance de generalização
    \item Reduz variância das métricas através da média dos folds
    \item Utiliza todo o conjunto de treino para avaliação
\end{itemize}

\subsection{Configurações dos Hiperparâmetros}

Para o spot-checking, foram utilizadas configurações padrão ou ligeiramente otimizadas para velocidade:

\begin{itemize}
    \item \textbf{Random Forest:} 50 árvores, max\_depth=20, n\_jobs=-1 (paralelo)
    \item \textbf{Gradient Boosting:} 50 árvores, max\_depth=5, learning\_rate=0.1
    \item \textbf{MLP:} 1 camada oculta com 50 neurônios, early stopping ativado
    \item \textbf{KNN:} k=5 vizinhos
    \item \textbf{Demais modelos:} Hiperparâmetros padrão do scikit-learn
\end{itemize}

\section{Spot-checking de Algoritmos}

\subsection{Metodologia dos Experimentos}

Os experimentos foram conduzidos seguindo o protocolo estabelecido:

\begin{enumerate}
    \item Carregamento do conjunto de treino pré-processado (3,874 amostras, 1,359 features)
    \item Execução de validação cruzada estratificada com 5 folds para cada algoritmo
    \item Cálculo das métricas de performance (Accuracy, Precision, Recall, F1-Score, ROC-AUC)
    \item Ranking dos modelos pela métrica Accuracy
    \item Avaliação dos top-3 modelos no conjunto de teste independente
\end{enumerate}

\subsubsection{Modelos com Desempenho Intermediário}

    \item \textbf{MLP Neural Network (79.43\% F1):} Desempenho razoável com maior variância (±0.91\%). ROC-AUC de 0.8905 indica boa capacidade discriminativa. Precision (79.26\%) ligeiramente inferior ao Recall (80.12\%).
    
    \item \textbf{Logistic Regression (79.14\% F1):} Modelo linear apresentou performance moderada e métricas bem balanceadas. ROC-AUC de 0.8745 mostra capacidade discriminativa adequada. Sugere que relações lineares explicam parcialmente o problema.
\end{itemize}

\subsubsection{Modelos com Desempenho Inferior}

\begin{itemize}
    \item \textbf{KNN (72.56\% F1):} Performance abaixo da média, com Precision (71.91\%) inferior ao Recall (73.77\%). ROC-AUC de 0.8205 ainda é razoável. Possivelmente prejudicado pela alta dimensionalidade (maldição da dimensionalidade).
    
    \item \textbf{SVM Linear (65.64\% F1):} Desempenho limitado com maior variância (±1.33\%). ROC-AUC de 0.7688 é o segundo pior. Confirma que o problema não é linearmente separável de forma simples.
    
    \item \textbf{Naive Bayes (58.46\% F1):} Pior desempenho geral. Precision (65.10\%) muito superior ao Recall (63.99\%), mas F1 baixo. ROC-AUC de 0.6834 indica fraca capacidade discriminativa. Forte violação da premissa de independência condicional entre features.
\end{itemize}

\subsection{Principais Observações}

\paragraph{1. Modelos baseados em árvores dominaram:}

Os três melhores modelos (Gradient Boosting, Decision Tree, Random Forest) são todos baseados em árvores de decisão, indicando que:

\begin{itemize}
    \item O problema apresenta relações não-lineares complexas entre features e target
    \item Interações entre descritores moleculares são importantes para a predição
    \item Particionamento recursivo do espaço de features é uma abordagem eficaz
\end{itemize}

\paragraph{2. Suspeita de Overfitting:}

As performances de 99.85\% (Gradient Boosting) e 98.04\% (Decision Tree) são excepcionalmente altas e levantam a suspeita de overfitting, considerando:

\begin{itemize}
    \item Alta dimensionalidade do dataset (1,359 features)
    \item Complexidade dos modelos de árvore
    \item Necessidade de validação no conjunto de teste independente
\end{itemize}

\paragraph{3. Modelos lineares têm limitações:}

O desempenho moderado de Logistic Regression (79\%) e fraco de SVM Linear (66\%) confirma que o problema \textbf{não é linearmente separável}, reforçando a necessidade de modelos não-lineares.

\paragraph{4. Impacto da alta dimensionalidade:}

O desempenho fraco do KNN (74\%) é característico da \textit{curse of dimensionality}, onde a noção de proximidade se torna menos significativa em espaços de alta dimensão.

\section{Otimização de Hiperparâmetros}

A segunda etapa do trabalho aprofundou a investigação dos três modelos mais promissores identificados no spot-checking: Gradient Boosting, Decision Tree e Random Forest. Antes da otimização, o pipeline experimental foi revisado para atender explicitamente ao requisito de prevenção de \textit{data leakage} destacado no enunciado do T2.

\subsection{Correções Metodológicas}

A implementação do T2 parte novamente do arquivo bruto \texttt{ames\_mutagenicity\_data.csv}, em vez de reutilizar diretamente os arquivos processados da etapa anterior. Esta decisão foi adotada para garantir que todas as transformações fossem aprendidas apenas nos dados de treinamento durante a validação cruzada.

As seguintes correções foram aplicadas:

\begin{itemize}
    \item Remoção das amostras com \texttt{Overall = 0}, mantendo a formulação binária do problema: mutagênico vs. não-mutagênico.
    \item Remoção das colunas auxiliares \texttt{TA98}, \texttt{TA100}, \texttt{TA102}, \texttt{TA1535} e \texttt{TA1537} das features. Estas colunas representam labels experimentais por cepa bacteriana e são diretamente relacionadas ao consenso \texttt{Overall}; portanto, seu uso como atributos levaria a vazamento de informação da variável alvo.
    \item Inclusão das etapas de imputação, remoção de baixa variância e normalização dentro de objetos \texttt{Pipeline} do scikit-learn.
    \item Separação de um conjunto de teste estratificado, correspondente a 20\% dos dados, utilizado apenas uma vez ao final da otimização.
\end{itemize}

Dessa forma, a otimização de hiperparâmetros foi conduzida somente sobre o conjunto de treino, usando validação cruzada estratificada, enquanto o conjunto de teste permaneceu isolado para a avaliação final.

\subsection{Estratégia de Busca}

Foi utilizada a biblioteca Optuna para automatizar a busca de hiperparâmetros. Para cada um dos três modelos, foram executados 100 \textit{trials} em um perfil pragmático de busca, avaliados por validação cruzada estratificada com 5 folds. A métrica principal de otimização foi o F1-score ponderado (\texttt{f1\_weighted}), escolhida por manter consistência com o critério de comparação do T1 e por lidar melhor com o desbalanceamento moderado entre classes.

Os espaços de busca foram definidos de acordo com os hiperparâmetros mais relevantes de cada família de modelos:

\begin{itemize}
    \item \textbf{Gradient Boosting:} número de estimadores, taxa de aprendizado, profundidade máxima, amostragem e parâmetros mínimos de divisão e folha.
    \item \textbf{Decision Tree:} critério de divisão, profundidade máxima, poda por \texttt{ccp\_alpha}, balanceamento de classes e parâmetros mínimos de divisão e folha.
    \item \textbf{Random Forest:} número de árvores, profundidade máxima, número de atributos por divisão, amostragem com reposição, balanceamento de classes e parâmetros mínimos de divisão e folha.
\end{itemize}

O perfil pragmático limitou combinações muito custosas, principalmente em modelos ensemble sobre dados de alta dimensionalidade. Assim, a busca priorizou a geração de uma avaliação final metodologicamente correta dentro do tempo disponível, mantendo a possibilidade de ampliar o número de \textit{trials} posteriormente.

O código da otimização está disponível em \texttt{src/t2\_hyperparameter\_optimization.py}. O notebook \texttt{notebooks/04\_hyperparameter\_optimization\_interpretability.ipynb} executa esse pipeline e salva automaticamente os resultados em \texttt{results/metrics/t2/}, \texttt{results/figures/t2/} e \texttt{results/models/t2/}.

\section{Conclusão}

Este trabalho realizou a caracterização do problema de predição de mutagenicidade Ames, o spot-checking inicial de 8 algoritmos de aprendizado de máquina e, na segunda etapa, a otimização e interpretação dos modelos mais promissores em um pipeline revisado para evitar vazamento de dados.

\subsection{Principais Achados}

\paragraph{1. Caracterização do Dataset:}

\begin{itemize}
    \item Dataset bem estruturado com 5,536 compostos e 1,359 features após pré-processamento
    \item Desbalanceamento moderado entre classes (56\% mutagênico vs 40\% não-mutagênico)
    \item Alta dimensionalidade (razão features/instâncias $\approx$ 0.25)
    \item Ausência de valores faltantes e duplicatas após tratamento inicial
\end{itemize}

\paragraph{2. Performance dos Algoritmos no T1:}

\begin{itemize}
    \item \textbf{Modelos baseados em árvores dominaram:} Gradient Boosting, Decision Tree e Random Forest foram os três modelos mais bem posicionados no spot-checking inicial.
    
    \item \textbf{Os resultados do T1 motivaram a escolha dos candidatos do T2:} os três modelos baseados em árvores foram selecionados para otimização por apresentarem os melhores resultados preliminares.
    
    \item \textbf{O T2 revisou o protocolo experimental:} a avaliação final deve ser interpretada a partir do pipeline corrigido, sem labels auxiliares como features e sem ajuste de pré-processamento fora da validação cruzada.
    
    \item \textbf{Modelos intermediários:} MLP (F1: 80.92\%, ROC-AUC: 0.902), SVM Linear (F1: 80.72\%, ROC-AUC: 0.892) e Logistic Regression (F1: 80.04\%, ROC-AUC: 0.881) apresentaram desempenho moderado similar
    
    \item \textbf{Alta dimensionalidade prejudicou KNN:} F1 de 73.38\% e ROC-AUC de 0.830 devido à maldição da dimensionalidade
    
    \item \textbf{Naive Bayes com pior desempenho:} F1 de 58.51\% e ROC-AUC de 0.683, confirmando forte violação da premissa de independência condicional
\end{itemize}

\paragraph{3. Natureza do Problema:}

O problema de predição de mutagenicidade Ames apresenta:

\begin{itemize}
    \item \textbf{Relações não-lineares complexas} entre descritores moleculares e mutagenicidade
    \item \textbf{Interações importantes} entre features, capturadas efetivamente por modelos de árvore
    \item \textbf{Separabilidade não-linear}, confirmada pelo desempenho superior de modelos não-lineares
\end{itemize}

\subsection{Algoritmos Mais Promissores}

Com base no spot-checking inicial, destacam-se três algoritmos selecionados para a etapa de otimização:

\begin{enumerate}
    \item \textbf{Gradient Boosting} --- modelo de boosting com alta capacidade de capturar relações não-lineares.
    \item \textbf{Decision Tree} --- modelo naturalmente interpretável e útil como referência para análise de regras.
    \item \textbf{Random Forest} --- ensemble de árvores com boa robustez e menor sensibilidade a uma única árvore ajustada.
\end{enumerate}

\subsection{Considerações Finais}

O spot-checking revelou que modelos baseados em árvores são candidatos adequados para este problema de classificação de compostos químicos. No T2, a otimização confirmou que o Random Forest foi o modelo mais competitivo quando avaliado em uma metodologia mais rigorosa, sem vazamento de dados e com o conjunto de teste preservado até a etapa final.

Os três modelos otimizados permitem comparar diferentes compromissos entre desempenho, robustez e interpretabilidade:

\begin{itemize}
    \item O \textbf{Random Forest} obteve o melhor resultado final, com F1 ponderado de 0.8289 e ROC-AUC de 0.9062.
    \item O \textbf{Gradient Boosting} teve desempenho próximo, mas inferior, com F1 ponderado de 0.8033.
    \item O \textbf{Decision Tree} ficou abaixo dos ensembles, indicando que uma única árvore foi menos robusta para este conjunto de descritores.
\end{itemize}

O presente trabalho estabeleceu um pipeline completo para desenvolvimento de modelos preditivos de mutagenicidade Ames, incluindo caracterização do problema, comparação preliminar de algoritmos, otimização de hiperparâmetros, avaliação final em teste e interpretação do melhor modelo. Como trabalhos futuros, poderiam ser investigadas técnicas adicionais de seleção de atributos, validação externa usando a partição original do artigo e comparação com modelos especializados para descritores moleculares.
